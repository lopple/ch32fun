# b003fast minichlink release assets

This branch adds a GitHub Actions release workflow for b003fast minichlink release candidates.

## Release workflow

Workflow file:

```text
.github/workflows/minichlink-release.yml
```

Release tags use this pattern:

```text
b003fast-minichlink-rc.*
```

Pushing a matching tag builds all release archives on GitHub and publishes a GitHub prerelease.
Manual `workflow_dispatch` runs can build the same artifacts without publishing a release.

## Targets

| Asset | Runner | Notes |
|---|---|---|
| `minichlink-windows-x86_64-<tag>.zip` | `ubuntu-24.04` | Cross-compiled with MinGW and packaged with `bin/minichlink.exe` plus `bin/libusb-1.0.dll`. |
| `minichlink-linux-x86_64-<tag>.tar.gz` | `ubuntu-24.04` | Built natively and packaged with `bin/minichlink`, `lib/minichlink.so`, and udev rules. |
| `minichlink-macos-x86_64-<tag>.tar.gz` | `macos-15-intel` | Built on an Intel macOS runner. |
| `minichlink-macos-arm64-<tag>.tar.gz` | `macos-14` | Built on an Apple Silicon runner so the binary does not require Rosetta. |

Each archive has one top-level directory and stores the executable under `bin/`.
The workflow also publishes `SHA256SUMS.txt` for package-index work.

## Local notes

The workflow is intentionally separate from the existing push/pull-request minichlink CI.
Release archives are generated by GitHub Actions and are not committed to the repository.
